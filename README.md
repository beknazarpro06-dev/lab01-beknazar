# Кофейня «Арча» — лабораторная работа №1

Учебный проект на семестр: сайт кофейни «Арча» в Бишкеке.

## Что сделано

- `index.html` — главная страница с семантической разметкой:
  `header`, `nav`, `main`, `section`, `footer`, `address`.
- Один `h1`, разделы на `h2`, списки `ul` и `ol`, `strong` и `em`,
  дата через `time`, внешняя ссылка с `rel="noopener noreferrer"`.
- Блок «Вопросы и ответы» на `details` / `summary`.
- `contacts.html` — вторая страница, связанная с главной относительными ссылками.

## Как запустить

Откройте папку в VS Code и выберите на `index.html`
**Open with Live Server** (или просто откройте файл в браузере).
